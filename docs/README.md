# `docs/` 项目文档与规划资产说明

本目录存放项目的**产品需求说明、设计规范、原始资产原件以及辅助初始化脚本**。
此目录为离线资产与说明文档，不会被打包编译进前端代码。

---

## 目录文件清单

| 文件 / 路径 | 说明 |
| :--- | :--- |
| **`Require.md`** | **核心产品需求说明书**：包含 AI 娘化极客独立站（AI-Chan Geek Merch）的商业背景、角色设定规范（5 大模型娘）、规避 Stripe/PayPal 自动化风控策略、功能模块规划及交付标准。 |
| **`setup_db.py`** | **PostgreSQL 数据库初始化脚本**：使用 Python `psycopg2` 快速在远端数据库创建 `products`, `orders`, `return_tickets`, `cart_sessions` 数据表。 |
| **`assets/characters/`** | **原始角色素材切图原件**：从原始插画素材中按网格高保真裁剪出的 5 大 AI 娘透明底全身立绘与圆形徽章高分辨率图片原件备份。 |
